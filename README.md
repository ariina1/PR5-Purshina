# PR5-Purshina — Обработчик анкет
Практическая работа по обработке строк, файлов и ошибок на Python.
## Назначение
Программа читает анкеты из `anketa.txt`, проверяет данные и разделяет их на корректные и некорректные.
## Формат анкеты
Каждая строка содержит четыре поля, разделённые точкой с запятой:
ФИО; электронная почта;телефон;группа
## Файлы результатов
- `ok.txt` — корректные анкеты.
- `errors.txt` — строки с ошибками и причины отклонения.
## Запуск
```bash
python main.py
```
## Запуск тестов
```bash
python -m pytest -q
```
## Автоматическая проверка
GitHub Actions запускает тесты при отправке изменений и создании Pull Request.
